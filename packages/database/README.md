# Database

This package is the database connector needed to read and write Datahub data
(users' object lists). Sawubona runs it against **Postgres** on Discovery One;
upstream used MySQL on PlanetScale. Drizzle ORM with `pg-core` and the
`postgres` (postgres-js) driver.

To connect via the app, set `DATABASE_URL` in `apps/researcher/.env.local`
(`postgresql://user:password@host:5432/database`). For scripts run from this
package, put it in `packages/database/.env.local`.

## Local Postgres with Docker

    ./scripts/create-database.sh      # starts postgres:16, prints DATABASE_URL

## Schema and migrations

`src/db/schema.ts` is the source of truth. `migrations/` holds a single
Postgres baseline (`0000_sawubona_postgres_baseline.sql`, generated by
drizzle-kit plus the `updated_at` trigger). The production tables on
Discovery One were created from the equivalent DDL in
`devops/terraform/servers/discovery-one/sql/`.

    npm run db:generate   # drizzle-kit generate:pg — after changing schema.ts
    npm run db:migrate    # apply migrations to DATABASE_URL

`db:generate` against a database that matches `schema.ts` must produce no new
migration; that is the check that code and database agree.
